# Socio Attendance System

A web-based attendance and socio organization management system.

## Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite for development

## Planned Features

- User authentication and role-based access
- Socio and member management
- Attendance tracking
- Activities and events
- Socio finances
- Reports and records

## Roles

- System Administrator
- Socio Moderator
- Socio Officers
- Socio Members

## Development

This project is being developed with IntelliJ IDEA and managed through GitHub.
